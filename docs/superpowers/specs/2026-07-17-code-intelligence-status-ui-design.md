# 源码智能状态 UI 优化设计

## 目标

让源码智能状态面板只展示当前有用的信息，并让完成/失败通知醒目、短暂且可关闭。

## 状态面板

- 首行保留“源码智能”标题和滑动开关。
- 显示明确的状态摘要：未启用、准备运行时、等待索引、建立索引、同步、重建、取消中、已就绪、失败或已中断。
- 处理中显示进度条、当前阶段和“取消任务”。
- 已就绪显示文件、符号、关系统计，以及存在时的最近同步时间，并提供同步和重建操作。
- 失败或中断显示醒目的错误卡片和“重试”操作。
- 项目路径始终显示；运行时仅在已知时显示。
- 不显示无意义占位项，例如“错误：无”“阶段：—”“尚未同步”和全零统计。
- 开关在 pending 时不可操作，但保持当前 enabled 意图对应的视觉位置与颜色。

## 顶部通知

- 通知固定在页面顶部居中，位于所有普通内容和 Popover 之上。
- 成功使用绿色样式，失败使用红色样式，并带状态图标。
- 通知出现后 4 秒自动淡出并卸载。
- 提供关闭按钮，用户可以立即移除。
- 同一时间最多显示一条通知；新通知替换旧通知并重新开始计时。
- 定时器生命周期只依赖通知实例，不依赖轮询返回的完整状态对象，避免轮询清理定时器后通知永久残留。

## 数据流

1. 轮询返回新的源码智能状态。
2. 仅在非终态进入 `ready` 或 `failed` 时创建通知。
3. 独立通知组件负责自动关闭和手动关闭。
4. 面板根据状态选择摘要、详情和合法操作，不渲染无效字段。

## 测试

- 测试不同状态下的面板可见字段和操作。
- 使用 fake timers 验证通知 4 秒后关闭。
- 验证后续相同状态轮询不会取消自动关闭。
- 验证新通知替换旧通知并重置计时。
- 验证手动关闭立即移除通知。
