# 源码智能开关与实时进度修正设计

## 范围

修正源码智能创建页和状态面板中的开关边界，并将构建中的装饰性进度条替换为由 CodeGraph 实际输出驱动的全流程百分比。完成状态保持现有绿色“源码索引已就绪”布局。

## 界面

- 创建页和状态面板共用确定性的滑块定位：关闭和开启时，圆形滑块均完整位于轨道内部。
- 外层卡片为开关保留稳定右边距，不允许开启状态越出边框。
- 构建中采用分区式布局：标题/开关、状态、整体进度、项目详情分区展示。
- 进度区域只显示“正在构建源码索引”、整体百分比和一条进度条。
- 成功后隐藏进度区域，切换为绿色“源码索引已就绪”、统计和同步/重建操作。
- 失败或取消后停止进度更新，显示对应错误或中断状态。

## 进度数据流

1. 索引命令启用 CodeGraph 可解析的详细进度输出。
2. 进程运行器在命令执行期间持续读取输出，而不是等进程退出后一次性读取。
3. 后端解析 CodeGraph 的阶段、当前值和总值。
4. 扫描、解析、存储、关系解析等阶段合成为单调递增的全流程 `0..99` 百分比；只有真实进度输出才能推动数值。
5. 百分比和阶段写入 Workspace 内部源码智能元数据。
6. 现有 REST 状态接口返回百分比，前端沿用活动任务轮询刷新。
7. 任务成功后状态切换为 `ready`，完成界面直接显示就绪，不保留 100% 进度条。

## 错误与并发

- 无法解析的输出忽略，不伪造进度。
- 百分比不得倒退，范围限制为 `0..99`；只有 `ready` 表示完成。
- 取消、失败和超时沿用现有状态机与进程树清理。
- 同一项目仍只允许一个索引任务，进度写入不得改变并发语义。

## 测试

- 进度输出解析和全流程百分比单调性。
- 运行中元数据与 REST 状态包含真实百分比。
- 成功、失败和取消时的进度终止行为。
- 前端构建中显示实际宽度/百分比，完成后隐藏进度条。
- 两处开关在 ON/OFF 状态均使用边界内定位。
- 运行源码智能后端测试、前端测试、类型检查和静态检查。
