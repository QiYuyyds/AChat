核心理念

不是终端，是群聊

传统编码 Agent 是一段孤立的终端记录。AChat 把它变成 IM 群聊。会话是工作空间，Agent 是联系人。

传统 Agent 终端
每次运行是孤立的终端记录，上下文丢失
手动复制粘贴传递上下文，容易出错
推理过程黑盒，事后难以追溯
串行执行，一个任务做完才能做下一个
AChat 群聊范式
会话即工作空间，历史持久化，跨 run 可追溯
Agent 是联系人，可 @ 提及，支持多会话并行
推理、工具调用、产物全程可见，可审批
Orchestrator 自动拆任务，多 Agent 并行调度

Agent 是联系人，对话是工作空间，Orchestrator 是群里的项目经理。

功能特性

一套完整的 Agent 协作工具链

从任务调度到知识检索，从记忆系统到可观测性，覆盖 Agent 协作全链路。

多 Agent 并行调度
Orchestrator 自动拆分任务，分配给最合适的 Agent 并行执行。DAG 波调度 + Worktree 隔离，递归深度上限 3 层
产物自动聚合
代码、文档、演示文稿统一管理，支持内联预览与二次编辑
本地优先部署
数据自主可控，基础设施可独立降级，Milvus / ES / Neo4j 缺一不阻断
RAG 混合检索
Milvus 向量 + Elasticsearch 全文 + Neo4j 知识图谱，三路融合检索
分层记忆系统
短期 / 会话 / 长期 / 偏好 / 图谱记忆，自动固化与衰减
代码图谱智能
CodeGraph 本地运行时 + code_explore 工具，Agent 理解项目结构
可观测性
OpenTelemetry + Phoenix 全链路追踪 + 评测系统，trace_enabled 开关即降级

代码、网页、文档，内联可预览

Agent 产出的产物不用下载，直接在对话里预览和二次编辑。
