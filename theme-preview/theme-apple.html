帮我看下 ChatPanel 的结构，哪些地方可以拆

看了下，ChatPanel 现在 1133 行，塞了四块东西：消息流、文件标签页、待审批面板、计划卡片。建议拆成四个独立组件，ChatPanel 只做布局编排。

fs_read chat-panel.tsx · 1133 行
// ChatPanel 应该只管这些 export function ChatPanel() { return ( <MessageList /> <FileTabBar /> <PendingReviewPanel /> <DispatchPlanCard /> ) }

拆完之后每个组件 200-300 行，单独可测。ChatPanel 本身压到 150 行以内。

FileTabBar 和 PendingReviewPanel 之间有状态依赖吗

有。PendingReviewPanel 审批通过后，文件会写进 workspace，FileTabBar 需要感知到新文件并自动打开。现在这个逻辑直接写在 ChatPanel 里，耦合比较紧。

建议在 useAppStore 里加一个 openFiles 的 selector，PendingReviewPanel 审批后调 openFile()，FileTabBar 订阅同一个 selector 自动更新。ChatPanel 不再插手这个流程。
